# POOP SCOOP - 排便管理システム 試作版

GitHub Pages で動かせる静的Webアプリの試作版です。

## 主な機能
- PC / タブレット / スマホ対応
- 利用者マスタ
- 排便・ケア記録
- 下剤記録
- 排便なし日数 / 下剤後経過時間の色付き表示
- 施設全体 / 利用者別の簡易統計・傾向表示
- CSV取込 / CSV出力
- 判定基準の設定
- 使い方ガイド
- ブラウザ localStorage への保存

## GitHub Pages での公開
1. このフォルダの中身を GitHub リポジトリへアップロード
2. GitHub の Settings → Pages
3. Branch を `main` / root に設定
4. 表示されたURLを開く

## 注意
これは架空データで試すためのプロトタイプです。
実在する利用者の個人情報・病名・服薬・排便記録を本番運用する場合は、認証、権限管理、監査ログ、暗号化、バックアップ、施設ごとのデータ分離などを追加してください。
