# LunaCare 排便管理システム Ver.0.2

GitHub Pages で動かせる試作版です。`index.html` だけで動作します。

## 主な機能
- 水色＋ミント基調のレスポンシブUI
- ホーム／記録／排便カレンダー／分析／メニュー
- 1人保存後に「次の利用者へ」連続入力
- 便状態を見た目で選択 → 自動でBristol 1〜7に変換
- 全体／個別の排便カレンダー
- カレンダーに便状態の数字、下剤使用を表示
- 排便回数、Bristol分布、排便間隔の簡易グラフ
- 薬あり／なし、薬名、カテゴリー、投与方法、投与量、時刻
- CSVの期間・対象者・出力内容指定
- CSV取込
- 使い方ガイド
- ブラウザ内（localStorage）保存

## GitHub Pages
1. ZIPを解凍
2. `index.html` と `README.md` をリポジトリのルートにアップロード
3. Settings → Pages
4. Source: `Deploy from a branch`
5. Branch: `main` / `(root)`
6. Save

## 注意
このVer.0.2は試作版です。データは各ブラウザ内に保存され、端末間で自動同期されません。
実在の利用者情報・病名・服薬情報等を使う本番運用では、認証・権限管理・監査ログ・暗号化・施設内規程等を含めた別設計が必要です。
